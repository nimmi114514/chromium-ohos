# 2026-10-28 本地构建交付记录

Chromium 158.0.8116.0 / OHOS API 26 / arm64-v8a，release签名包。

## 本次状态

- 历史与书签的原生工具栏弹窗使用真实数据源，并跟随Chromium主题。
- 修复关闭后未释放delegate、仍监听书签模型而访问悬空控件的cppcrash；
  Widget和delegate由显式宿主管理，关闭时撤销监听及异步任务。
- 新增收藏通过Chromium原生BookmarkCurrentTab流程，避免弹窗内直接修改模型时的生命周期冲突。
- OHOS V8内嵌builtins使用复制回退，跳过启动阶段的页重映射优化；
  保留系统安全模式和可写代码内存权限对JIT的门控，不引入JITFort。
- 原生构建、HAP构建、235项运行资源/原生内容检查及签名校验通过，已覆盖安装。
  用户反馈本次问题正常；不声称所有功能、所有网站或完整性能对比均已验收。
